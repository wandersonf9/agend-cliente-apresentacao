# Agend Cliente SaaS

Sistema de agendamento e gestão para salões de beleza e estabelecimentos de estética. O projeto está em versão beta e busca reunir a rotina do estabelecimento e a experiência de agendamento dos clientes em uma aplicação web.

## Funcionalidades

- Cadastro de estabelecimentos e catálogo de serviços.
- Agendamento online por link individual do estabelecimento.
- Gestão de clientes, agenda e equipe.
- Acessos com permissões diferentes conforme o papel da pessoa na equipe.
- Registro de despesas e acompanhamento financeiro.

## Tecnologias

- **Interface:** HTML, CSS e JavaScript.
- **Servidor:** Node.js e Express.
- **Banco de dados:** PostgreSQL.
